# Demo script (5 minutes)

## Setup
1. `source .venv/bin/activate && python -m accessshift`
2. Camera permission granted
3. Accessibility permission granted if showing system mouse
4. Backup video ready

## Script

**0:00–0:40 — Problem**  
Healthcare UIs block people with motor and cognitive impairments. We use a laptop webcam and one desktop app.

**0:40–1:40 — SmartInterface**  
Show complex booking. Toggle accessible mode. Complete a step with large targets.

**1:40–2:50 — SteadyHand**  
Enable tremor simulation. Attempt tiny slots. Enable SteadyHand. Show accuracy change.

**2:50–4:10 — GazeControl**  
Calibrate. Navigate with gaze + blink. Speak confirmation with pyttsx3.

**4:10–5:00 — Engine + next steps**  
Switch ALS / Parkinson's / Cognitive profiles. Mention PyInstaller packaging and clinic deployment.
