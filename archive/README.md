# Archived Hackathon Artifacts

This directory preserves early hackathon artifacts from the original prototype for reference:

- `archive/legacy_ui/`: The initial PySide6 desktop prototype.
- `archive/docs/`: Original AccessShift and natHacks planning and handoff notes.

Active development lives in:

- `backend/` (Python FastAPI engine and OS hooks)
- `frontend/` (React, TypeScript, and Tailwind interface)
- `src-tauri/` (Tauri v2 native desktop shell, tray, and global hotkeys)
