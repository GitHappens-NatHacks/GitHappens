Use it on other webpages

  1. Open chrome://extensions in Chrome or edge://extensions in Edge. In Opera, try opera://extensions.
  2. Enable Developer mode and choose Load unpacked.
  3. Select the extracted AccessShift_Extension folder containing manifest.json.
  4. Open an ordinary webpage, choose AccessShift from the extensions menu, adjust your preferences and choose Apply to this page.
  5. Use Restore page to undo. Esc pauses the virtual pointer.

No Python, Node, installer or account is required. Reading settings and experimental color filters affect webpages. SteadyHand uses a virtual pointer; it does not stabilize the Windows mouse cursor.
